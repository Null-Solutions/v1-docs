After you sign in with an approved wallet, the app's `/` route is your portfolio.

## What you can review

<CardGroup cols={2}>
  <Card title="Portfolio summary" icon="chart-no-axes-combined">
    View the portfolio value and performance summary associated with the signed-in wallet.
  </Card>

  <Card title="Balances" icon="wallet-cards">
    Review wallet assets and pool-share balances representing your Null positions.
  </Card>

  <Card title="History" icon="history">
    Review the position activity available for the wallet.
  </Card>

  <Card title="Watchlist" icon="bookmark">
    Return to markets you have saved for later review.
  </Card>
</CardGroup>

## Manage a position

Select a position to review its market and available actions. Deposits mint pool shares; redemptions burn shares and return the resulting collateral to your wallet.

<Note>
Portfolio values can change as market prices, funding, collateral value, and pool state change. Displayed values are not guaranteed redemption amounts.
</Note>

To enter a new position, start at [Fund Account](/private-beta/fund-account). To exit an existing position, read [Redeeming](/redeeming).
