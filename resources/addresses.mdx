## Indexer Source

The public indexer tracks the current Sepolia `NullV1Factory` from block `11321037`.

Dynamic markets are discovered from the factory's `CreateMarket` event. Each market deploys its own Receiver pool and Payer pool, so pool addresses should be read from the market, factory events, Lens responses, or the indexer rather than hardcoded.

<Note>
  The deployed Sepolia Lens exposes the core `previewState`, `simulateState`,
  `previewMarket`, and `simulateMarket` interface. Check the deployed bytecode
  and ABI before using newer collateral-metrics helpers from the latest source.
</Note>

## What To Hardcode

Hardcode shared infrastructure addresses like `NullV1Factory`, both routers, the enabled FRM, `NullV1Lens`, and `NullV1Multicall` per chain.

Do not hardcode market pool addresses unless you intentionally pin to one specific market. Receiver and Payer pools are deployed per market and should normally be discovered from `NullV1Factory`, `NullV1Market`, `NullV1Lens`, or indexer data.

See [Integrator Quickstart](/developers-tab/integrator-quickstart), [Router](/developers-tab/router), and [Indexer Integration](/contracts/integration/indexer) for how these addresses fit into a full integration.
