market status as described in [Oracles](/markets/oracles), and route updates through `NullV1Router`.

## ABI and artifact source

For production, use the ABI shown by Etherscan for each verified address linked above. For proxies, take the ABI from the linked implementation contract. Match the verified contract name and compiler metadata before generating types.

The examples in these docs use minimal inline ABIs so readers can understand individual calls. They are not a canonical ABI package. Null V1 does not currently publish an npm SDK or ABI package.
