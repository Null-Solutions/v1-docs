A market is identified by `(collateral, oracle, frm)`. The factory stores one market per exact tuple. Dependencies are fixed at initialization.

## Prerequisites

- Nonzero ERC-20 `collateral`
- Nonzero `INullV1Oracle` whose `price()` returns a nonzero `1e36`-scaled price during init
- Nonzero `INullV1FundingRateModel` already enabled via `enableFrm(frm)`

```solidity
require(factory.isFrmEnabled(address(frm)), "FRM not enabled");
address existing =
    factory.getMarket(address(collateral), address(oracle), address(frm));
```

Only the factory owner can enable an FRM. There is no disable.

## Choose the correct router

All supported oracles are pull-based, so the router can update the oracle before factory init reads `price()`:

- **Pyth** → pre-funded `NullV1PayableRouter`
- **Chainlink V3 / V11** → fee-less `NullV1Router`

```solidity
INullV1Market market = router.createMarket(
    factory,
    collateral,
    oracle,
    frm,
    updateData
);
```

Call `factory.createMarket` directly only when the oracle already has a readable price — the factory does not update it.

## Factory behavior

Creation reverts for zero deps, disabled FRM, or an existing tuple. Otherwise the factory:

1. Clones and initializes `NullV1Market`
2. Clones and initializes Receiver and Payer pools
3. Reads the initial oracle price and initializes the FRM
4. Records `getMarket[collateral][oracle][frm]`

```solidity
event CreateMarket(
    address indexed collateral,
    address indexed oracle,
    address indexed frm,
    address market,
    address receiverPool,
    address payerPool
);
```

Retrieve later with `getMarket(collateral, oracle, frm)`. See [Factory](/contracts/factory) · [Oracles](/markets/oracles) · [Live deployments](/resources/addresses).
