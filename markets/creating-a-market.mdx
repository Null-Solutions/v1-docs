A Null V1 market is identified by the tuple
`(collateral, oracle, frm)`: an ERC-20 collateral token, an oracle, and a
funding-rate model (FRM). The factory stores one market for each exact tuple.
These dependencies are fixed when the market clone is initialized.

## Prerequisites

- a nonzero ERC-20 `collateral`
- a nonzero `INullV1Oracle` whose `price()` returns a nonzero `1e36`-scaled
  price during initialization
- a nonzero `INullV1FundingRateModel`
- an FRM that the factory owner has already enabled with `enableFrm(frm)`

```solidity
require(factory.isFrmEnabled(address(frm)), "FRM not enabled");
address existing =
    factory.getMarket(address(collateral), address(oracle), address(frm));
```

Only the factory owner can enable an FRM, and the current factory has no
disable operation.

## Choose the correct router

All supported oracles are pull oracles, so the router can update the oracle
before factory initialization reads `price()`:

- Pyth: use the pre-funded `NullV1PayableRouter`
- Chainlink V3 or V11: use the fee-less `NullV1Router`

Both expose the same market-creation arguments:

```solidity
INullV1Market market = router.createMarket(
    factory,
    collateral,
    oracle,
    frm,
    updateData
);
```

For Pyth, the payable router calls `getUpdateFee` and forwards the fee from its
own ETH balance. For Chainlink, the fee-less router calls nonpayable `update`
and forwards no ETH.

You may call `factory.createMarket(collateral, oracle, frm)` directly only when
the oracle already has a readable price. The factory does not update it.

## Factory behavior

Creation reverts for zero collateral, zero oracle, zero FRM, an FRM that is not
enabled, or an existing tuple. Otherwise the factory:

1. clones `NullV1Market`
2. initializes it with collateral, oracle, FRM, and the pool implementation
3. clones and initializes receiver and payer pools
4. reads the initial oracle price and initializes the FRM
5. records `getMarket[collateral][oracle][frm]`

The emitted event is:

```solidity
event CreateMarket(
    address indexed collateral,
    address indexed oracle,
    address indexed frm,
    address market,
    address receiverPool,
    address payerPool
);
```

Use `getMarket(collateral, oracle, frm)` to retrieve the market later.
