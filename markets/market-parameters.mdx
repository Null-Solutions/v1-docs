A market is uniquely identified by three dependency addresses fixed during initialization:

```text
(collateral, oracle, frm)
```

The factory creates at most one market per tuple. A live market has no setter for any dependency. To use different collateral, oracle, or FRM, create a new tuple and therefore a new market.

## Immutable identity

<ParamField path="collateral" type="IERC20" required>
  ERC-20 held by the market and both pools. Accounting is in raw units of this token. See [Collateral](/markets/collateral).
</ParamField>

<ParamField path="oracle" type="INullV1Oracle" required>
  Tracked asset price at `1e36`. Settlement requires nonzero. See [Oracles](/markets/oracles).
</ParamField>

<ParamField path="frm" type="INullV1FundingRateModel" required>
  Funding-rate model queried every settlement. The factory must enable it before market creation.
</ParamField>

<Warning>
A market has no `asset()` or `mu()` identity accessor. Read `market.collateral()` for its collateral token. Each Receiver and Payer pool implements ERC-4626, so `pool.asset()` returns that same market collateral. Funding parameters such as `mu` live on the FRM.
</Warning>

The factory has no FRM disable function. Even if factory governance enables another FRM later, the `frm()` of an existing market does not change.

## Other fixed addresses

| Field | Role |
| --- | --- |
| `factory` | Cloned/registered the market; owner sets fees and enables FRMs |
| `receiverPool` | ERC-4626 pool that receives the tracked price return |
| `payerPool` | ERC-4626 reserve with the opposite price exposure |

Both pools are cloned at init and emitted in `CreateMarket`.

## Mutable fees

Factory owner can set three fees. Entry and exit default to 25 bps and are capped at 250 bps. The collateral fee is disabled.

| Accessor | Charged on | Maximum |
| --- | --- | ---: |
| `entryFee()` | `deposit` / `mint`, on settleable-R notional | 250 bps (2.5%) |
| `exitFee()` | `withdraw` / `redeem`, same notional | 250 bps (2.5%) |
| `collateralFee()` | Pool assets, annualized during settlement | 0 (disabled) |

Entry and exit credit the opposite pool unless the factory was deployed with `allowProtocolFees`. `sweepFees()` settles first, then pays the factory owner any `protocolFees`. Details: [Fees](/developers/fees).

## Standard imbalance FRM

`NullV1ImbalanceFundingRateModel` constructor params (WAD):

<ParamField path="mu" type="uint256" required>
  Sensitivity and absolute rate bound. `0 < mu <= 1e18`. Default deployment: `1e18` (`mu = 1`).
</ParamField>

<ParamField path="targetCoverage" type="uint256" required>
  Target Payer coverage `c = P/R`. `0 < targetCoverage <= 1e18`. Default: `0.5e18` (`c = 0.5`).
</ParamField>

```text
f = mu * (cR - P) / (cR + P)
```

- Positive `f` → Receiver pays Payer
- Negative `f` → Payer pays Receiver
- Zero at `P = cR` or if either pool is empty
- `|f| <= mu` by construction
- Annual funding transfer across the pools = `f * R`

The standard imbalance FRM is stateless. A different enabled `INullV1FundingRateModel` can be used only when creating another market; it cannot replace the FRM on a live market. Always identify `market.frm()` before interpreting rates. Worked tables: [Funding and carry](/learn/funding-and-carry).

## Read onchain

```solidity
address factory      = market.factory();
address collateral   = address(market.collateral());
address oracle       = address(market.oracle());
address frm          = address(market.frm());
address receiverPool = address(market.receiverPool());
address payerPool    = address(market.payerPool());

uint16 entryFee      = market.entryFee();
uint16 exitFee       = market.exitFee();
uint16 collateralFee = market.collateralFee();

uint256 mu = NullV1ImbalanceFundingRateModel(frm).mu();
uint256 targetCoverage = NullV1ImbalanceFundingRateModel(frm).targetCoverage();
```

Discover with `factory.getMarket(collateral, oracle, frm)`. Settlement order: [Settlement](/developers/settlement).
