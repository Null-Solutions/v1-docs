Oracles supply the normalized price used when a market settles. Supported implementations are all **pull-based**:

- Pyth
- Chainlink Data Streams V3 (crypto)
- Chainlink Data Streams V11 (RWA / session feeds)

## Price scale

One base asset in quote units, scaled by `1e36`:

```solidity
uint256 price = oracle.price(); // 200 * 10^36 → 200 quote units
```

## Choose an implementation

| Oracle | Router | Fee |
| --- | --- | --- |
| Pyth | `NullV1PayableRouter` | Native fee paid from router ETH |
| Chainlink V3 | `NullV1Router` | Fee-less |
| Chainlink V11 | `NullV1Router` | Fee-less |

## Update flow

Fetch a signed payload and pass it as `updateData` on router create / deposit / redeem. Nonempty arrays update the oracle before the market op.

```solidity
router.depositMarket(
    market,
    receiverAssets,
    payerAssets,
    minReceiverShares,
    minPayerShares,
    deadline,
    updateData
);
```

Callers never attach `msg.value` for Pyth — the payable router pays from its balance.

<Warning>
Router type is part of the integration. The fee-less router cannot pay a Pyth update fee.
</Warning>

## Freshness and 10-day escape

Normal freshness threshold: **60 seconds**.

| Age of stored price | `price()` behavior |
| --- | --- |
| ≤ 60s old (or ≤ 60s in the future) | Accepted |
| > 60s and < 10 days | `StalePrice()` revert |
| ≥ 10 days | Last stored positive price returned |

The escape lives in each oracle's `price()` — it is not a separate redemption mode and does not refresh the stored price. Update acceptance is narrower (see Pyth/Chainlink refs).

<Warning>
The 10-day path restores liveness after prolonged outage. Treat the market as degraded and account for stale-price risk.
</Warning>
