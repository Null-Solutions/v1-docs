Null V1 charges three types of fees across its pools: an entry fee on deposits, an exit fee on redemptions, and an annualized collateral fee charged during market updates. All fee values are expressed in basis points (bps), where 1 bp = 0.01%. The protocol owner sets each fee, but every fee is bounded by an on-chain constant that cannot be exceeded.

<Note>
All fee parameters are set by the protocol owner and are bounded by immutable on-chain constants. No fee can ever exceed its corresponding maximum, regardless of any future governance action.
</Note>

## Entry fee

On `deposit`, the entry fee is included in the assets paid and deducted before shares are calculated. On `mint`, the fee is added to the raw assets required for the requested shares.

| Property | Value |
|---|---|
| Maximum | `500` bps (5%) |
| Applied on | `deposit` and `mint` calls |
| Accrues to | Market `protocolFees`; transferred on `sweepFees()` |
| On-chain constant | `MAX_ENTRY_FEE = 500` |

**Example:** If the entry fee is 50 bps (0.5%) and you deposit 1,000 USDC, the fee-on-total formula is `ceil(1,000 × 50 / 10,050)` in raw token units: approximately 4.975125 USDC at 6 decimals. Approximately 995.024875 USDC is used to calculate shares.

To read the current entry fee for a market:

```ts
const entryFeeBps = await market.entryFee(); // e.g. 50 for 0.5%
```

## Exit fee

On `redeem`, the exit fee is deducted from the gross assets represented by the burned shares. On `withdraw`, the fee is added to the raw pool debit required to deliver the requested net assets.

| Property | Value |
|---|---|
| Maximum | `500` bps (5%) |
| Applied on | `redeem` and `withdraw` calls |
| Accrues to | Market `protocolFees`; transferred on `sweepFees()` |
| On-chain constant | `MAX_EXIT_FEE = 500` |

**Example:** If the exit fee is 30 bps (0.3%) and your shares have a gross redemption value of 1,000 USDC, the fee-on-total formula is `ceil(1,000 × 30 / 10,030)` in raw token units: approximately 2.991027 USDC at 6 decimals. You receive approximately 997.008973 USDC.

To read the current exit fee for a market:

```ts
const exitFeeBps = await market.exitFee(); // e.g. 30 for 0.3%
```

## Collateral fee

The collateral fee is an annualized fee charged on Receiver and Payer pool balances during market updates. It is not a percentage of measured yield. For example, if collateral earns 5% externally and `collateralFee` is 100 bps (1% annualized), the net collateral carry before funding is roughly 4%.

| Property | Value |
|---|---|
| Maximum | `500` bps (5% annualized) |
| Applied on | Receiver and Payer pool collateral balances over elapsed time |
| Collected by | Protocol owner via `sweepFees()` after accrual |
| On-chain constant | `MAX_COLLATERAL_FEE = 500` |

Collateral fees accrue into the market's `protocolFees` balance during state updates. They are excluded from Receiver/Payer settlement and remain in the market until the protocol owner calls `sweepFees()`.

To read the current collateral fee for a market:

```ts
const collateralFeeBps = await market.collateralFee(); // e.g. 100 for 1% annualized
```

## Reading all fees at once

You can read all fee values in a single multicall or sequential read before you commit capital:

```ts
const [entryFee, exitFee, collateralFee] = await Promise.all([
  market.entryFee(),
  market.exitFee(),
  market.collateralFee(),
]);

console.log(`Entry fee:  ${Number(entryFee)  / 100}%`);
console.log(`Exit fee:   ${Number(exitFee)   / 100}%`);
console.log(`Collateral fee: ${Number(collateralFee) / 100}% annualized`);
```

## How preview functions account for fees

Both `previewDeposit` and `previewRedeem` incorporate the relevant pool fee, so do not apply a second manual deduction. They use the last settled market state, however, and router amounts for ERC-4626 collateral are denominated in the vault underlying rather than collateral shares.

<CodeGroup>

```ts previewDeposit (entry fee included)
// Returns shares AFTER the entry fee is deducted from assets
const sharesOut = await receiverPool.previewDeposit(assetsIn);
```

```ts previewRedeem (exit fee included)
// Returns assets AFTER the exit fee is deducted from the gross redemption value
const assetsOut = await receiverPool.previewRedeem(sharesIn);
```

</CodeGroup>

<Tip>
Use the preview functions as fee-aware estimates and add a suitable slippage margin. For ERC-4626 collateral, also apply the collateral vault's wrap or unwrap conversion before using router minimums.
</Tip>

## Fee summary

<Note>
All maximums are enforced by immutable on-chain constants. The protocol owner can only set fees at or below these ceilings.
</Note>

| Fee type | Basis points max | Percentage max | Applies to | Collected |
|---|---|---|---|---|
| Entry fee | 500 | 5% | `deposit` and `mint` | Accrues during entry |
| Exit fee | 500 | 5% | `withdraw` and `redeem` | Accrues during exit |
| Collateral fee | 500 | 5% annualized | Pool assets over elapsed time | Accrues during settlement |
