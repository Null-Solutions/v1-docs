`NullV1Factory` deploys one market for each unique `(collateral, oracle, frm)` tuple. It is also the canonical registry of deployed markets and approved funding-rate models (FRMs).

## Market key

```solidity
function getMarket(
    address collateral,
    address oracle,
    address frm
) external view returns (address market);
```

Returns the registered market, or `address(0)` if the tuple has not been created.

## Funding-rate models

```solidity
function owner() external view returns (address);
function isFrmEnabled(address frm) external view returns (bool);
function enableFrm(address frm) external;
```

Only the factory owner can call `enableFrm`. Enabling is irreversible: the factory has no disable function. A model must be enabled before it can be used by `createMarket`.

`enableFrm` reverts with:

- `ZeroFrm()` when `frm` is the zero address.
- `FrmAlreadyEnabled(address frm)` when it is already enabled.
- OpenZeppelin `OwnableUnauthorizedAccount(address account)` when the caller is not the owner.

## Create a market

```solidity
function createMarket(
    IERC20 collateral,
    INullV1Oracle oracle,
    INullV1FundingRateModel frm
) external returns (INullV1Market market);
```

Market creation is permissionless, but the FRM must already be enabled. The factory deploys a market clone and its receiver and payer pool clones, initializes them, then registers the market under the tuple.

The supplied dependencies must satisfy the contract assumptions: collateral transfers must be exact and non-reentrant, oracle prices must be nonzero and scaled by `1e36`, and the FRM must not revert, re-enter, or return a rate that overflows settlement math.

`createMarket` reverts with:

- `ZeroCollateral()`
- `ZeroOracle()`
- `ZeroFrm()`
- `FrmNotEnabled(address frm)`
- `MarketExists(address collateral, address oracle, address frm)`
- `ZeroOraclePrice()` if initialization reads a zero oracle price
- `NoDelegateCall()` when `createMarket` is entered through `delegatecall`

## Events

```solidity
event EnableFrm(address indexed frm);

event CreateMarket(
    address indexed collateral,
    address indexed oracle,
    address indexed frm,
    address market,
    address receiverPool,
    address payerPool
);
```

Index `CreateMarket` from the factory deployment block to discover every market and both of its pools.
