`NullV1PythOracle` wraps one Pyth price feed. It reads the Pyth contract,
validates recency and positivity, and returns a `1e36`-scaled price.

## Update data

Fetch signed update bytes for `oracle.priceId()` from Pyth Hermes:

```text
GET https://hermes.pyth.network/v2/updates/price/latest?ids[]=<priceId>
```

Pass the returned `binary.data` elements as `bytes[] updateData`. The oracle
rejects an empty array and arrays longer than 3,300 entries.

```typescript
import { HermesClient } from "@pythnetwork/hermes-client";

const hermes = new HermesClient("https://hermes.pyth.network");
const priceId = await oracle.read.priceId();
const response = await hermes.getLatestPriceUpdates([priceId]);
const updateData: `0x${string}`[] = response.binary.data.map(
  (hex) => `0x${hex}`
);
```

## Payable routing

```solidity
uint256 fee = oracle.getUpdateFee(updateData);
oracle.update{value: fee}(updateData);
uint256 currentPrice = oracle.price();
```

<Note>
  Use `NullV1PayableRouter` for Pyth. The router reads the fee and pays it from
  its own pre-funded native-currency balance. Sending ETH with the user's market
  operation is not the funding path. If the router balance is too low, it
  reverts with `InsufficientUpdateFeeBalance`.
</Note>

Do not route Pyth updates through the fee-less `NullV1Router`: it calls the
nonpayable update interface and forwards no native fee.

The Pyth oracle forwards exactly the required fee to Pyth and refunds excess
`msg.value` to its caller. A second update in the same block is skipped and any
attached value is refunded.

## Update validation

After calling Pyth, the oracle requires the new `publishTime` to be strictly
newer than the previous value, not in the future, and no more than 60 seconds
old. A failed check reverts the entire update.

## Price normalization

Pyth prices carry a signed `expo`:

```text
normalizedPrice = pythPrice * 10^(36 + expo)
```

For `price = 300000` and `expo = -2`, the result is
`3000 * 10^36`. A non-positive price, zero publish time, or exponent below
`-36` reverts with `InvalidPrice`.

## Staleness and escape behavior

`price()` accepts a publish time within 60 seconds of the current block,
including up to 60 seconds in the future. It reverts when the age is greater
than 60 seconds but less than 10 days. Once the age is exactly 10 days or more,
it returns the old positive price as an emergency availability escape.

<Warning>
  A 10-day-old price is not fresh. The escape behavior exists to unblock
  settlement after a prolonged outage and should be treated as degraded mode.
</Warning>

## Creation

Create clone instances through `NullV1PythOracleFactory`:

```solidity
INullV1Oracle oracle = factory.createOracle(
    priceId,
    baseName,
    baseSymbol,
    quoteName,
    quoteSymbol
);
```

The implementation's display key is `keccak256("PYTH_CORE_PULL")`.
