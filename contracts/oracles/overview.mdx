A Null market stores one oracle address for its lifetime. Spot settlement calls `oracle.price()`, which returns a `1e36`-scaled price of the tracked asset.

The supported price oracles are Chainlink Data Streams:

- **V3** for a single 24/7 feed.
- **V11** for session feeds (regular, extended, overnight) on assets that do not trade all week.

Both are pull oracles. The router calls `update(bytes[])` with a signed report before the market reads `price()`. The Chainlink update fee reported to the router is zero. Use `NullV1Router`. Do not send ETH with the call.

Integration steps: [Chainlink Data Streams](/contracts/oracles/chainlink).

## Morpho oracles are separate

Margin books do not use the Chainlink oracle as their Morpho price source. They use [Morpho oracles](/contracts/oracles/morpho), which convert Receiver shares through the pool's previews.

## Freshness

If `price()` reverts, settlement reverts and the trade does not land. Pass a fresh `updateData` when the stored report is outside the oracle's accepted window. Pass `[]` only when the stored price is still valid. Never fabricate report bytes.

Market-creation and trade routing: [Oracles](/markets/oracles).
