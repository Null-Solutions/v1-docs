`NullV1Lens` projects market settlement without changing state. Prices passed to Lens must be nonzero and scaled by `1e36`.

## Response types

```solidity
struct MarketState {
    uint256 lastUpdate;
    uint256 receiverPool;
    uint256 payerPool;
    uint256 protocolFees;
    uint256 price;
}

struct SimulateResponse {
    MarketState state;
    uint256 totalAssets;
    uint256 receiverTotalSupply;
    uint256 payerTotalSupply;
    int256 fundingRate;
    uint256 collateralRate;
    uint256 collateralSharePrice;
}
```

- `state` is the projected settled state.
- `totalAssets` is the collateral token balance held by the market before projection.
- `receiverTotalSupply` and `payerTotalSupply` are the current pool share supplies.
- `fundingRate` is the signed annualized FRM rate, WAD-scaled. Positive means receivers pay payers; negative means payers pay receivers.
- `collateralRate` is the WAD-scaled supply APR computed for Morpho Vault V2 collateral.
- `collateralSharePrice` is the WAD-scaled underlying-equivalent value of one collateral vault share.

Within `simulateMarket`, each collateral metric is best-effort: a failed external walk produces zero for that field rather than reverting the whole response. Zero can therefore mean unavailable, not necessarily an economic value of zero.

## State simulation

```solidity
function previewState(
    address market
) external view returns (MarketState memory);

function simulateState(
    address market,
    uint256 externalPrice
) external view returns (MarketState memory);

function previewMarket(
    address market
) external view returns (SimulateResponse memory);

function simulateMarket(
    address market,
    uint256 price
) public view returns (SimulateResponse memory);
```

`previewState` and `previewMarket` use `market.oracle().priceView()`. The `simulate` variants use the caller-provided price. All four reconcile the current market collateral balance, accrue collateral fees, read `frm.fundingRateView`, and apply funding and price settlement in memory.

These are projections at the block being queried. They do not update oracle storage or market state. A zero price reverts with `ZeroOraclePrice()`, and `priceView()` may retain the oracle implementation's own staleness and revert behavior.

## Collateral metrics

```solidity
function computeCollateralSharePrice(
    address collateral
) external view returns (uint256);
```

Reads the ERC-4626 `asset()`, converts one whole collateral share using `convertToAssets`, and normalizes the result to `1e18` using the underlying token decimals. It reverts if the collateral does not provide the required ERC-20/ERC-4626 methods.

```solidity
function computeCollateralRate(
    address collateral
) external view returns (uint256);
```

Computes the allocation-weighted Morpho Vault V2 supply APR. It inspects at most 16 adapters and 64 market IDs per adapter. A vault with zero total assets returns zero; incompatible collateral can revert.

```solidity
function computeAdapterWeightedApr(
    address vault,
    address adapter
) external view returns (
    uint256 weightedApr,
    uint256 assets
);
```

Returns the sum of `marketSupplyApr * expectedSupplyAssets` and the summed expected supply assets for the inspected adapter markets. If `adapter.parentVault() != vault`, it returns `(0, 0)`. `computeCollateralRate` sums `weightedApr` and divides by the vault's total assets.

Morpho market supply APR is derived from the adaptive-curve IRM's per-second borrow rate, annualized over `31_536_000` seconds and multiplied by utilization. The calculation does not subtract the Morpho market fee.
