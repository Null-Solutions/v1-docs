The `INullV1Market` contract sits at the heart of every Null V1 market. It owns the collateral deposited by liquidity providers across both the receiver and payer pools, maintains the authoritative on-chain state (balances, oracle price, share price, and accrued fees), and enforces the fee schedule. Both pools call back into the market to synchronise state before every mutating operation, meaning the market always reflects the latest oracle price before assets change hands. You will rarely call the market directly as an end-user — the [Router](/contracts/router) handles that — but understanding its interface is essential when building integrations, dashboards, or automated fee-collection bots.

## State

### `state()`

Returns a snapshot of the full market state at the current block. Calling this function is the fastest way to get all critical figures in a single RPC round-trip.

<ResponseField name="timestamp" type="uint256">
  The block timestamp of the last state update.
</ResponseField>

<ResponseField name="receiverPoolAssets" type="uint256">
  The total assets (in collateral token decimals) currently attributed to the receiver pool after PnL settlement.
</ResponseField>

<ResponseField name="payerPoolAssets" type="uint256">
  The total assets attributed to the payer pool after PnL settlement.
</ResponseField>

<ResponseField name="price" type="uint256">
  The oracle price used in the most recent state update, expressed in the oracle's native precision.
</ResponseField>

<ResponseField name="protocolFees" type="uint256">
  Accumulated but not yet collected protocol fees denominated in the collateral token.
</ResponseField>

<ResponseField name="sharePrice" type="uint256">
  The internal share price (WAD-scaled, 1e18 = 1.0) computed at the last state update.
</ResponseField>

```solidity
(
    uint256 timestamp,
    uint256 receiverPoolAssets,
    uint256 payerPoolAssets,
    uint256 price,
    uint256 protocolFees,
    uint256 sharePrice
) = market.state();
```

---

### `currentSharePrice()`

Returns the live share price computed from the latest oracle reading without requiring a full state update transaction. Use this for read-only pricing in UIs and keepers.

## Immutable Accessors

| Function | Return type | Description |
|---|---|---|
| `factory()` | `address` | The `INullV1Factory` that deployed this market. |
| `asset()` | `IERC20` | The ERC-20 collateral token. |
| `oracle()` | `INullV1Oracle` | The price oracle supplying external reference prices. |
| `mu()` | `uint24` | The drift parameter μ governing funding rate dynamics. |
| `receiverPool()` | `INullV1Pool` | The ERC-4626 pool for the receiver (long funding) position. |
| `payerPool()` | `INullV1Pool` | The ERC-4626 pool for the payer (short funding) position. |

## Fees

Null V1 markets collect three distinct fees, each capped by a protocol-enforced maximum. All fee values are expressed in basis points (1 bp = 0.01%).

| Accessor | Constant cap | Maximum |
|---|---|---|
| `entryFee()` | `MAX_ENTRY_FEE` | 500 bp (5%) |
| `exitFee()` | `MAX_EXIT_FEE` | 500 bp (5%) |
| `yieldFee()` | `MAX_YIELD_FEE` | 5000 bp (50%) |

<Note>
  `updateFees()` is restricted to the protocol owner. If any other address calls it, the transaction reverts with `NotProtocolOwner(address caller, address protocolOwner)`.
</Note>

### `collectFees()`

Transfers all accrued protocol fees from the market to the protocol owner and returns the collected amount. Anyone may call this function — there is no access restriction — making it straightforward for off-chain keepers to trigger collection.

```solidity
uint256 collected = market.collectFees();
```

<Tip>
  Monitor the `protocolFees` field returned by `state()` and trigger `collectFees()` when the balance crosses a meaningful threshold to avoid large single transfers and simplify accounting.
</Tip>

## Events

### `StateUpdated`

Emitted each time the market's internal state is refreshed, typically triggered by pool deposits, withdrawals, or explicit keeper calls.

<ResponseField name="timestamp" type="uint256 (indexed)">
  The block timestamp at which the state was updated.
</ResponseField>

<ResponseField name="receiverPoolAssets" type="uint256">
  The receiver pool's total assets after the update.
</ResponseField>

<ResponseField name="payerPoolAssets" type="uint256">
  The payer pool's total assets after the update.
</ResponseField>

<ResponseField name="price" type="uint256">
  The oracle price used for this state update.
</ResponseField>

<ResponseField name="protocolFees" type="uint256">
  The cumulative uncollected protocol fees as of this update.
</ResponseField>

<ResponseField name="sharePrice" type="uint256">
  The share price (WAD-scaled) computed during this update.
</ResponseField>

---

### `FeesUpdated`

Emitted when the protocol owner changes the market's fee schedule.

<ResponseField name="entryFee" type="uint16">
  The new entry fee in basis points.
</ResponseField>

<ResponseField name="exitFee" type="uint16">
  The new exit fee in basis points.
</ResponseField>

<ResponseField name="yieldFee" type="uint16">
  The new yield fee in basis points.
</ResponseField>

---

### `FeesCollected`

Emitted when accrued protocol fees are swept out of the market.

<ResponseField name="fee" type="uint256">
  The total amount of collateral token transferred to the protocol owner.
</ResponseField>

## Errors

| Error | Trigger condition |
|---|---|
| `NotProtocolOwner(address caller, address protocolOwner)` | A restricted function (e.g. `updateFees`) was called by an address that is not the protocol owner. |
| `ZeroAsset()` | The market was initialised with a zero asset address (deployment-time guard). |
| `ZeroOraclePrice()` | The oracle returned a zero price during a state update. |
| `InvalidFee(uint256 fee, uint256 maxFee)` | A proposed fee value exceeds the corresponding maximum constant. |
| `NotDeployedMarket()` | A call came from an address that is not the authorised receiver or payer pool. |

<Warning>
  If your oracle can transiently return zero (e.g. during a price feed outage), any market state update will revert with `ZeroOraclePrice()`. Ensure your oracle implementation returns a sentinel non-zero value or pauses cleanly before deploying in production.
</Warning>
