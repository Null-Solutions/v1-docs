Each `NullV1Market` holds the collateral for its receiver and payer pools. The market owns settlement accounting; the pools own ERC-4626 share accounting.

## State

```solidity
function state() external view returns (
    uint256 lastUpdate,
    uint256 receiverPoolAssets,
    uint256 payerPoolAssets,
    uint256 protocolFees,
    uint256 price
);
```

- `lastUpdate` is set at initialization and after each completed state update.
- `receiverPoolAssets` and `payerPoolAssets` are denominated in collateral token units.
- `protocolFees` are collateral units reserved for the protocol owner.
- `price` is the last accepted `1e36`-scaled oracle price.

## Accessors

```solidity
function factory() external view returns (address);
function collateral() external view returns (IERC20);
function oracle() external view returns (INullV1Oracle);
function frm() external view returns (INullV1FundingRateModel);
function receiverPool() external view returns (INullV1Pool);
function payerPool() external view returns (INullV1Pool);
function entryFee() external view returns (uint16);
function exitFee() external view returns (uint16);
function collateralFee() external view returns (uint16);
```

Fees are basis points. Entry and exit default to 25 bps and are capped at `250` (2.5%). They are charged on settleable-R notional. The collateral fee is capped at `0`. Where entry and exit land depends on the factory's `allowProtocolFees` flag: the opposite pool, or `protocolFees`. See [Fees](/developers/fees).

## Settlement

State accrual is interaction-driven. There is no permissionless public “poke”: `updateState()` is callable only by the two pools. Every pool deposit, mint, withdrawal, or redemption settles first. `setFees` and `sweepFees` also settle before applying their changes.

Settlement reconciles the market's actual collateral balance, accrues collateral fees, obtains the signed WAD-scaled funding rate from `frm`, and settles funding and price PnL between pools. Positive funding means receivers pay payers; negative funding means payers pay receivers.

When both pools have assets, price PnL is skipped if a move exceeds the time-scaled circuit-breaker cap; funding still settles and `UpdateState.circuitBreakerFired` is `true`. If either pool is empty, both price PnL and funding transfer are skipped and the flag is `false`. Settlement transfers are capped so the debited pool retains `MIN_POOL_ASSETS` (`1e6` raw collateral units).

## Owner operations

The protocol owner is the current `owner()` of the factory.

```solidity
function setFees(
    uint16 newEntryFee,
    uint16 newExitFee,
    uint16 newCollateralFee
) external;

function sweepFees() external returns (uint256 amount);
```

`sweepFees` settles, transfers all accrued protocol fees to the protocol owner, and emits `CollectFees` only when the amount is nonzero.

## Events

```solidity
event UpdateState(
    uint256 indexed lastUpdate,
    uint256 receiverPoolAssets,
    uint256 payerPoolAssets,
    uint256 protocolFees,
    uint256 price,
    bool circuitBreakerFired
);

event SetFees(
    uint16 entryFee,
    uint16 exitFee,
    uint16 collateralFee
);

event CollectFees(uint256 fee);
```

## Errors

| Error | Condition |
|---|---|
| `NotProtocolOwner(address caller, address protocolOwner)` | A non-owner calls `setFees` or `sweepFees`. |
| `InvalidFee(uint256 fee, uint256 maxFee)` | A configured fee exceeds its cap. |
| `NotPool(address caller, address receiverPool, address payerPool)` | A non-pool caller invokes a pool-only callback. |
| `NotDeployedMarket()` | The factory registry no longer maps this market's `(collateral, oracle, frm)` tuple to this market. |
| `ZeroOraclePrice()` | The oracle returns zero during initialization or settlement. |
| `ZeroCollateral()` / `ZeroOracle()` | Initialization receives a zero dependency. |
