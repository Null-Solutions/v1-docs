A Null V1 indexer discovers markets from the factory, indexes market settlement events, and tracks pool ERC-20 balances. Use Lens or Multicall for current projections; events remain the historical record.

## Discover markets

Start at the factory deployment block and index:

```solidity
event CreateMarket(
    address indexed collateral,
    address indexed oracle,
    address indexed frm,
    address market,
    address receiverPool,
    address payerPool
);

event EnableFrm(address indexed frm);
```

Persist all six `CreateMarket` fields. Market identity is the exact `(collateral, oracle, frm)` tuple, which can also be resolved with:

```solidity
factory.getMarket(collateral, oracle, frm);
```

Subscribe to both pool addresses immediately so early share transfers are not missed.

## Index market state

```solidity
event UpdateState(
    uint256 indexed lastUpdate,
    uint256 receiverPoolAssets,
    uint256 payerPoolAssets,
    uint256 protocolFees,
    uint256 price,
    bool circuitBreakerFired
);

event SetFees(
    uint16 entryFee,
    uint16 exitFee,
    uint16 collateralFee
);

event CollectFees(uint256 fee);
```

`UpdateState` is emitted when pool execution or an owner fee operation settles the market. There is no periodic permissionless update function. Store `circuitBreakerFired`: when true, the new price was recorded but price PnL for that update was skipped; funding still settled.

Prices are scaled by `1e36`. Pool assets and protocol fees are raw market-collateral units. If collateral is an ERC-4626 vault, use Lens `collateralSharePrice` or the vault conversion to express those units in underlying terms.

## Track positions

Pool positions are ERC-20 balances. Index standard `Transfer` events on both receiver and payer pools:

```solidity
event Transfer(
    address indexed from,
    address indexed to,
    uint256 value
);
```

Use standard ERC-4626 events for transaction context:

```solidity
event Deposit(
    address indexed sender,
    address indexed owner,
    uint256 assets,
    uint256 shares
);

event Withdraw(
    address indexed sender,
    address indexed receiver,
    address indexed owner,
    uint256 assets,
    uint256 shares
);
```

Pool shares use `collateral.decimals() + 10` decimals because the ERC-4626 decimals offset is 10.

## Read projected state

```solidity
struct SimulateResponse {
    MarketState state;
    uint256 totalAssets;
    uint256 receiverTotalSupply;
    uint256 payerTotalSupply;
    int256 fundingRate;
    uint256 collateralRate;
    uint256 collateralSharePrice;
}
```

Use `previewMarket(market)` for a settlement projection at `oracle.priceView()`, or `simulateMarket(market, price)` for a caller-provided `1e36`-scaled price. `fundingRate` is signed and WAD-scaled. `collateralRate` and `collateralSharePrice` are unsigned and WAD-scaled.

For batches:

```solidity
multicall.previewAll(lens, markets);
multicall.simulateAll(lens, markets, externalPrices);
```

The response order matches the market order. A reverted per-market call produces an all-zero `SimulateResponse` rather than reverting the batch. Record that entry as unavailable, not as an empty market. `simulateAll` itself reverts with `LengthMismatch` if the market and price arrays differ in length.

## Metadata

The market oracle exposes:

```solidity
oracle.baseName();
oracle.baseSymbol();
oracle.quoteName();
oracle.quoteSymbol();
```

Cache these values for display labels. They are interface methods, but an indexer should still handle individual RPC failures defensively.
