Build integrations from public onchain interfaces. Discover markets from the factory, index market and pool events for history, and use Lens or Multicall for current projections.

## Discover markets

Start at the canonical factory deployment block listed under [Live deployments](/resources/addresses). On Sepolia, that block is `11321037`.

```solidity
event CreateMarket(
    address indexed collateral,
    address indexed oracle,
    address indexed frm,
    address market,
    address receiverPool,
    address payerPool
);

event EnableFrm(address indexed frm);
```

Persist all six `CreateMarket` fields. A market's identity is the exact `(collateral, oracle, frm)` tuple. Verify a record with the public `factory.getMarket(collateral, oracle, frm)` function.

Subscribe to both pool addresses immediately so early share transfers are not missed. Do not hardcode per-market pools.

```ts
import { parseAbiItem } from "viem";

const factory = "0xc4d61E729225E8fA6612969fA705a36a8446B6CF" as const;
const createMarketEvent = parseAbiItem(
  "event CreateMarket(address indexed collateral, address indexed oracle, address indexed frm, address market, address receiverPool, address payerPool)",
);

const logs = await publicClient.getLogs({
  address: factory,
  event: createMarketEvent,
  fromBlock: 11_321_037n,
  toBlock: "latest",
});

const discoveredMarkets = logs.flatMap((log) => {
  const { collateral, oracle, frm, market, receiverPool, payerPool } = log.args;
  if (
    !collateral ||
    !oracle ||
    !frm ||
    !market ||
    !receiverPool ||
    !payerPool
  ) {
    return [];
  }

  return [{ collateral, oracle, frm, market, receiverPool, payerPool }];
});
```

Persist `discoveredMarkets` with idempotent writes keyed by chain ID, factory address, and market address. Handle chain reorganizations by retaining block number, block hash, transaction hash, and log index.

## Index market state

```solidity
event UpdateState(
    uint256 indexed lastUpdate,
    uint256 receiverPoolAssets,
    uint256 payerPoolAssets,
    uint256 protocolFees,
    uint256 price,
    bool circuitBreakerFired
);

event SetFees(uint16 entryFee, uint16 exitFee, uint16 collateralFee);
event CollectFees(uint256 fee);
```

`UpdateState` fires when a pool action or a fee operation settles the market. There is no periodic permissionless settlement call. When `circuitBreakerFired` is true, the market records the new price but skips price PnL; funding still settles.

Prices are `1e36`-scaled. Pool assets and protocol fees are raw market-collateral units. If collateral is ERC-4626, use Lens `collateralSharePrice` or vault conversion for underlying terms.

## Track positions

Index ERC-20 `Transfer` on both pools, plus ERC-4626:

```solidity
event Deposit(address indexed sender, address indexed owner, uint256 assets, uint256 shares);
event Withdraw(
    address indexed sender,
    address indexed receiver,
    address indexed owner,
    uint256 assets,
    uint256 shares
);
```

Pool shares use `collateral.decimals() + 10` decimals.

Use `Transfer` as the source of truth for current share balances. Use `Deposit` and `Withdraw` for action history and asset/share amounts. A router operation can emit vault, collateral, and pool events in the same transaction; filter by known contract address instead of symbol.

## Projected state

```solidity
struct SimulateResponse {
    MarketState state;
    uint256 totalAssets;
    uint256 receiverTotalSupply;
    uint256 payerTotalSupply;
    int256 fundingRate;
    uint256 collateralRate;
    uint256 collateralSharePrice;
}
```

- `previewMarket(market)` projects settlement at `oracle.priceView()`.
- `simulateMarket(market, price)` projects settlement at a caller-provided nonzero `1e36` price.

For batches, call the public Multicall functions:

```solidity
multicall.previewAll(lens, markets);
multicall.simulateAll(lens, markets, externalPrices);
```

Response order matches input order. A reverted per-market call yields an all-zero `SimulateResponse` — treat as unavailable, not empty. `simulateAll` reverts with `LengthMismatch` if array lengths differ.

Lens responses are current block snapshots, not historical records. They do not update oracle storage or market state. Store events for history and refresh projections at the cadence your application needs.

## Metadata

```solidity
oracle.baseName();
oracle.baseSymbol();
oracle.quoteName();
oracle.quoteSymbol();
```

Cache these values as display labels and handle individual RPC failures. Pool token names follow `<baseName> Receiver Share` / `<baseName> Payer Share`, with symbols `r<baseSymbol>` / `p<baseSymbol>`. Determine the side from the market's pool addresses or `poolKind()`, not from labels.

## Collateral units

Keep these units distinct in your schema:

```text
market state assets = market collateral units
pool totalAssets    = market collateral units
pool balances       = Null pool share units
router vault input  = ERC-4626 underlying units
```

If `collateral.asset()` succeeds, the router treats collateral as ERC-4626:

```text
underlying ↔ market collateral vault shares ↔ Null pool shares
```

On Sepolia `nUSDC` markets, the underlying is `MockUSDC`. Verify the addresses before applying those labels. Do not assume all markets use that pair.

## Reliability checklist

- Backfill from the canonical factory deployment block before following the chain head.
- Deduplicate logs and support rollback on reorganization.
- Subscribe to newly discovered market and pool addresses without delay.
- Read token decimals onchain and store raw integer values.
- Treat all-zero batch simulations as unavailable.
- Reconcile indexed pool balances against `balanceOf` after backfills or reorgs.
