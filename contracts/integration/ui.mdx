Reads: `NullV1Lens` (and optionally Multicall for batches). Writes: the router that matches the market's oracle fee model.

| Oracle | Router |
| --- | --- |
| Chainlink (fee-less updates) | `NullV1Router` |
| Pyth (native update fee) | Pre-funded `NullV1PayableRouter` |

Both expose the same `createMarket`, `depositMarket`, and `redeemMarket` signatures. Do not send ETH with user calls. Addresses: [Live deployments](/resources/addresses).

## Read a market

```solidity
struct SimulateResponse {
    MarketState state;
    uint256 totalAssets;
    uint256 receiverTotalSupply;
    uint256 payerTotalSupply;
    int256 fundingRate;
    uint256 collateralRate;
    uint256 collateralSharePrice;
}
```

`previewMarket(market)` projects settlement using `oracle.priceView()`. `fundingRate` is signed WAD APR; `collateralRate` and `collateralSharePrice` are unsigned WAD metrics.

```ts
import { formatUnits } from "viem";

const response = await publicClient.readContract({
  address: lens,
  abi: lensAbi,
  functionName: "previewMarket",
  args: [market],
});

const fundingPercent = Number(formatUnits(response.fundingRate, 18)) * 100;
const collateralAprPercent =
  Number(formatUnits(response.collateralRate, 18)) * 100;
```

Keep values as `bigint` for math. A zero collateral metric can mean unsupported or unavailable — Lens catches failures on those external reads.

<Note>
Deployed Sepolia Lens may lag newer collateral-metric helpers in latest source. Check the deployed ABI before relying on newer fields.
</Note>

## Deposit

Approve the token the router pulls: market collateral for plain ERC-20, or vault **underlying** for ERC-4626 collateral. Amounts are in that same unit.

```ts
const deadline = BigInt(Math.floor(Date.now() / 1000) + 300);
const total = receiverAssets + payerAssets;

await walletClient.writeContract({
  address: tokenToPull,
  abi: erc20Abi,
  functionName: "approve",
  args: [router, total],
});

const hash = await walletClient.writeContract({
  address: router,
  abi: routerAbi,
  functionName: "depositMarket",
  args: [
    market,
    receiverAssets,
    payerAssets,
    minReceiverShares,
    minPayerShares,
    deadline,
    updateData,
  ],
});
```

Set one side's assets and mins to `0n` for single-side deposits. Full guide: [Depositing](/developers/depositing).

## Redeem

Approve pool share tokens to the router (`msg.sender` must own the shares being burned).

```ts
await walletClient.writeContract({
  address: receiverPool,
  abi: erc20Abi,
  functionName: "approve",
  args: [router, receiverShares],
});

const hash = await walletClient.writeContract({
  address: router,
  abi: routerAbi,
  functionName: "redeemMarket",
  args: [
    market,
    receiverShares,
    0n,
    minReceiverAssets,
    0n,
    deadline,
    updateData,
  ],
});
```

For ERC-4626 collateral, returned amounts and minimums are underlying units. Full guide: [Redeeming](/developers/redeeming).

## Preview caveats

Pool `preview*` uses last settled state; execution settles first. Refresh `previewMarket` near submit and leave slippage room.

For ERC-4626 collateral: router deposit amount is underlying; `pool.previewDeposit` expects vault shares. Quote vault wrap, then pool — never pass underlying straight into the pool preview.

## Oracle update data

Pass `[]` to skip. With nonempty data, fee-less router calls `update(bytes[])`; payable router pays from its ETH balance (`InsufficientUpdateFeeBalance` if underfunded). Payload fetch is oracle-specific — see [Oracles](/markets/oracles).
