Use `NullV1Lens` for display data and the router matching the market's oracle fee model for writes:

- `NullV1Router` for fee-less updates such as Chainlink.
- Pre-funded `NullV1PayableRouter` for native-fee updates such as Pyth.

Both routers expose the same `createMarket`, `depositMarket`, and `redeemMarket` signatures. Do not send ETH with user calls.

## Read a market

```solidity
struct SimulateResponse {
    MarketState state;
    uint256 totalAssets;
    uint256 receiverTotalSupply;
    uint256 payerTotalSupply;
    int256 fundingRate;
    uint256 collateralRate;
    uint256 collateralSharePrice;
}
```

`previewMarket(market)` projects settlement using `oracle.priceView()`. `fundingRate` is a signed WAD-scaled annualized rate; `collateralRate` and `collateralSharePrice` are unsigned WAD-scaled metrics.

```typescript
import { formatUnits } from "viem";

const response = await publicClient.readContract({
  address: lensAddress,
  abi: lensAbi,
  functionName: "previewMarket",
  args: [marketAddress],
});

const fundingPercent =
  Number(formatUnits(response.fundingRate, 18)) * 100;
const collateralAprPercent =
  Number(formatUnits(response.collateralRate, 18)) * 100;
```

Keep values as `bigint` for calculations. A zero collateral metric can mean unsupported or unavailable because Lens catches failures in those external reads.

## Deposit

Approve the router for the token it pulls. For plain ERC-20 market collateral this is the collateral token. For ERC-4626 market collateral this is the vault's underlying token, and `receiverAssets` and `payerAssets` are underlying-token units.

```typescript
const deadline = BigInt(Math.floor(Date.now() / 1000) + 300);

await walletClient.writeContract({
  address: tokenToPullAddress,
  abi: erc20Abi,
  functionName: "approve",
  args: [routerAddress, receiverAssets + payerAssets],
  account,
});

const hash = await walletClient.writeContract({
  address: routerAddress,
  abi: routerAbi,
  functionName: "depositMarket",
  args: [
    marketAddress,
    receiverAssets,
    payerAssets,
    minReceiverShares,
    minPayerShares,
    deadline,
    updateData,
  ],
  account,
});
```

Set one side's assets and minimum shares to zero to deposit only into the other side.

## Redeem

The router burns shares owned by `msg.sender`, so approve it on each pool used by the redemption.

```typescript
await walletClient.writeContract({
  address: receiverPoolAddress,
  abi: erc20Abi,
  functionName: "approve",
  args: [routerAddress, receiverShares],
  account,
});

const hash = await walletClient.writeContract({
  address: routerAddress,
  abi: routerAbi,
  functionName: "redeemMarket",
  args: [
    marketAddress,
    receiverShares,
    0n,
    minReceiverAssets,
    0n,
    deadline,
    updateData,
  ],
  account,
});
```

For ERC-4626 market collateral, returned amounts and minimums are underlying-token units because the router unwraps collateral before checking slippage.

## Preview caveats

Pool `previewDeposit` and `previewRedeem` use the last settled market state, while execution settles first. Refresh `NullV1Lens.previewMarket` near submission and include a suitable slippage margin.

For ERC-4626 collateral, a router deposit amount is underlying units, but `pool.previewDeposit` expects collateral-vault share units. First quote the vault wrapping conversion, then quote the pool; do not pass underlying units directly to the pool preview.

## Oracle update data

Pass `[]` to skip an update. With nonempty data:

- `NullV1Router` calls the fee-less oracle `update(bytes[])`.
- `NullV1PayableRouter` obtains the fee and pays it from its existing ETH balance.

Fetching and validating update payloads is oracle-specific. A payable-router call reverts with `InsufficientUpdateFeeBalance` if its pre-funded balance cannot cover the fee.
