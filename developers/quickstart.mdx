This guide targets Ethereum mainnet and shows an ERC-4626 collateral flow using the generic names `collateralVault` and `underlying`.

Do not run the examples until [Ethereum deployments](/resources/addresses) publishes canonical deployment data. Never substitute addresses, deployment blocks, collateral, markets, or oracles from another network.

## Prerequisites

- A browser wallet connected to Ethereum mainnet
- `viem` installed in your app
- Published Ethereum infrastructure constants and a published market tuple
- The verified oracle type and any required signed update payload

This page uses minimal inline ABIs because no ABI package is assumed. For production, source ABIs from verified contract source or canonical deployment artifacts.

## 1. Build typed configuration

Copy published values from [Ethereum deployments](/resources/addresses) once available. Keep infrastructure and selected-market data typed and explicit:

```ts
import type { Address } from "viem";

interface PublishedEthereumDeployment {
  chainId: 1;
  factory: Address;
  router: Address;
  payableRouter: Address;
}

interface PublishedMarket {
  collateralVault: Address;
  underlying: Address;
  oracle: Address;
  frm: Address;
  oracleKind: "chainlink" | "pyth";
}

interface IntegrationConfig
  extends PublishedEthereumDeployment,
    PublishedMarket {}

// Populate these only from canonical published Ethereum deployment data.
declare const publishedEthereumDeployment: PublishedEthereumDeployment;
declare const selectedPublishedMarket: PublishedMarket;

const config = {
  ...publishedEthereumDeployment,
  ...selectedPublishedMarket,
} satisfies IntegrationConfig;
```

These are required inputs, not suggested constants. If any field is unavailable, stop configuration and wait for canonical publication.

## 2. Create clients and minimal ABIs

```ts
import {
  createPublicClient,
  createWalletClient,
  custom,
  http,
  parseAbi,
} from "viem";
import { mainnet } from "viem/chains";

if (config.chainId !== mainnet.id) {
  throw new Error("IntegrationConfig must contain Ethereum mainnet data");
}

const injectedProvider = (
  window as Window & { ethereum?: Parameters<typeof custom>[0] }
).ethereum;
if (!injectedProvider) throw new Error("Connect a browser wallet");

const publicClient = createPublicClient({
  chain: mainnet,
  transport: http(),
});
const walletClient = createWalletClient({
  chain: mainnet,
  transport: custom(injectedProvider),
});
const [account] = await walletClient.requestAddresses();
if (!account) throw new Error("Approve a wallet account");

const factoryAbi = parseAbi([
  "function getMarket(address collateral, address oracle, address frm) view returns (address market)",
]);
const marketAbi = parseAbi([
  "function collateral() view returns (address)",
  "function receiverPool() view returns (address)",
  "function payerPool() view returns (address)",
  "function state() view returns (uint256 lastUpdate, uint256 receiverPoolAssets, uint256 payerPoolAssets, uint256 protocolFees, uint256 price)",
]);
const poolAbi = parseAbi([
  "function previewDeposit(uint256 assets) view returns (uint256 shares)",
  "function previewRedeem(uint256 shares) view returns (uint256 assets)",
  "function balanceOf(address owner) view returns (uint256)",
  "function approve(address spender, uint256 amount) returns (bool)",
]);
const vaultAbi = parseAbi([
  "function asset() view returns (address)",
  "function previewDeposit(uint256 assets) view returns (uint256 shares)",
  "function previewRedeem(uint256 shares) view returns (uint256 assets)",
]);
const erc20Abi = parseAbi([
  "function decimals() view returns (uint8)",
  "function approve(address spender, uint256 amount) returns (bool)",
]);
const routerAbi = parseAbi([
  "function depositMarket(address market, uint256 receiverAssets, uint256 payerAssets, uint256 minReceiverShares, uint256 minPayerShares, uint256 deadline, bytes[] updateData) returns (uint256 receiverShares, uint256 payerShares)",
  "function redeemMarket(address market, uint256 receiverShares, uint256 payerShares, uint256 minReceiverAssets, uint256 minPayerAssets, uint256 deadline, bytes[] updateData) returns (uint256 receiverAssets, uint256 payerAssets)",
]);
```

## 3. Resolve and validate the market

```ts
import { zeroAddress, type Hex } from "viem";

const market = await publicClient.readContract({
  address: config.factory,
  abi: factoryAbi,
  functionName: "getMarket",
  args: [config.collateralVault, config.oracle, config.frm],
});
if (market === zeroAddress) {
  throw new Error("No market exists for the configured tuple");
}

const [marketCollateral, receiverPool, payerPool, state, vaultUnderlying] =
  await Promise.all([
    publicClient.readContract({
      address: market,
      abi: marketAbi,
      functionName: "collateral",
    }),
    publicClient.readContract({
      address: market,
      abi: marketAbi,
      functionName: "receiverPool",
    }),
    publicClient.readContract({
      address: market,
      abi: marketAbi,
      functionName: "payerPool",
    }),
    publicClient.readContract({
      address: market,
      abi: marketAbi,
      functionName: "state",
    }),
    publicClient.readContract({
      address: config.collateralVault,
      abi: vaultAbi,
      functionName: "asset",
    }),
  ]);

if (marketCollateral.toLowerCase() !== config.collateralVault.toLowerCase()) {
  throw new Error("Configured collateralVault does not match the market");
}
if (vaultUnderlying.toLowerCase() !== config.underlying.toLowerCase()) {
  throw new Error("Configured underlying does not match collateralVault.asset()");
}

const [, receiverPoolAssets, payerPoolAssets] = state;
const coverageWad =
  receiverPoolAssets === 0n
    ? undefined
    : (payerPoolAssets * 10n ** 18n) / receiverPoolAssets; // P/R
const payerInstantaneousLeverageWad =
  payerPoolAssets === 0n
    ? undefined
    : (receiverPoolAssets * 10n ** 18n) / payerPoolAssets; // L = R/P

const router =
  config.oracleKind === "pyth" ? config.payableRouter : config.router;
const updateData: Hex[] = []; // Only while the stored oracle price is usable.
```

Coverage is `P/R`. `L = R/P` is the leverage Payer has at this market state. It is not a funding rate. Each ratio is undefined when its denominator is zero.

For a fresh update, fetch signed payloads before submitting. Follow [Oracle update flow](/markets/oracles#update-flow) and the implementation-specific [Pyth](/contracts/oracles/pyth#update-data) or [Chainlink](/contracts/oracles/chainlink) instructions. Never fabricate payload bytes.

## 4. Preview and deposit

This example deposits into Receiver only. The router wraps `underlying` into `collateralVault` shares; pool previews accept those vault-share units.

```ts
import { parseUnits } from "viem";

const underlyingDecimals = await publicClient.readContract({
  address: config.underlying,
  abi: erc20Abi,
  functionName: "decimals",
});
const receiverAssets = parseUnits("100", underlyingDecimals);
const collateralShares = await publicClient.readContract({
  address: config.collateralVault,
  abi: vaultAbi,
  functionName: "previewDeposit",
  args: [receiverAssets],
});
const estimatedReceiverShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewDeposit",
  args: [collateralShares],
});

const slippageBps = 50n;
const minReceiverShares =
  (estimatedReceiverShares * (10_000n - slippageBps)) / 10_000n;

const approvalHash = await walletClient.writeContract({
  account,
  address: config.underlying,
  abi: erc20Abi,
  functionName: "approve",
  args: [router, receiverAssets],
});
await publicClient.waitForTransactionReceipt({ hash: approvalHash });

const depositHash = await walletClient.writeContract({
  account,
  address: router,
  abi: routerAbi,
  functionName: "depositMarket",
  args: [
    market,
    receiverAssets,
    0n,
    minReceiverShares,
    0n,
    BigInt(Math.floor(Date.now() / 1000) + 5 * 60),
    updateData,
  ],
});
await publicClient.waitForTransactionReceipt({ hash: depositHash });
```

Pool previews use the last settled state. Execution settles first, so keep a nonzero minimum on every active side.

## 5. Preview and redeem

For ERC-4626 collateral, convert the pool's vault-share quote to `underlying` before setting the router minimum.

```ts
const receiverShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "balanceOf",
  args: [account],
});
const estimatedCollateralShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewRedeem",
  args: [receiverShares],
});
const estimatedUnderlying = await publicClient.readContract({
  address: config.collateralVault,
  abi: vaultAbi,
  functionName: "previewRedeem",
  args: [estimatedCollateralShares],
});
const minReceiverAssets =
  (estimatedUnderlying * (10_000n - slippageBps)) / 10_000n;

const shareApprovalHash = await walletClient.writeContract({
  account,
  address: receiverPool,
  abi: poolAbi,
  functionName: "approve",
  args: [router, receiverShares],
});
await publicClient.waitForTransactionReceipt({ hash: shareApprovalHash });

const redeemHash = await walletClient.writeContract({
  account,
  address: router,
  abi: routerAbi,
  functionName: "redeemMarket",
  args: [
    market,
    receiverShares,
    0n,
    minReceiverAssets,
    0n,
    BigInt(Math.floor(Date.now() / 1000) + 5 * 60),
    updateData,
  ],
});
await publicClient.waitForTransactionReceipt({ hash: redeemHash });
```
