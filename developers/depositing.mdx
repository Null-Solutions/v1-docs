Depositing supplies collateral to the Receiver pool, the Payer pool, or both. Use a router for production UIs. It supports both sides in one transaction, deadlines, minimum shares, oracle updates, and ERC-4626 collateral wrapping.

Use `NullV1Router` for Chainlink and `NullV1PayableRouter` for Pyth. See [Router](/developers/router).

## Choose the input token

Read the market's `collateral()` before building the transaction. Then probe that token's ERC-4626 `asset()` function:

| Market collateral                   | Router input                           | Amount units      | Approval                                 |
| ----------------------------------- | -------------------------------------- | ----------------- | ---------------------------------------- |
| `asset()` reverts or is unavailable | Market collateral token                | Market collateral | Approve the router for market collateral |
| `asset()` succeeds                  | Vault underlying returned by `asset()` | Vault underlying  | Approve the router for the underlying    |

The router uses the same detection rule. A successful `asset()` call selects the ERC-4626 path. If another required vault call then fails, the transaction reverts rather than falling back to plain ERC-20 handling.

On the current Sepolia deployment, markets collateralized by `nUSDC` use `MockUSDC` as router input:

```text
MockUSDC underlying → nUSDC vault shares → Receiver or Payer pool shares
```

Do not label every collateral token as `nUSDC` or every underlying as `MockUSDC`. Those names apply only to deployments that use those contracts.

## Quote the complete unit pipeline

For plain ERC-20 collateral:

```text
router input (collateral) → pool.previewDeposit(collateral) → pool shares
```

For ERC-4626 collateral:

```text
router input (underlying)
  → collateralVault.previewDeposit(underlying)
  → pool.previewDeposit(vault shares)
  → pool shares
```

Apply slippage once, to the final pool-share quote:

```ts
const BPS = 10_000n;
const slippageBps = 50n; // 0.50%

function applySlippageFloor(quotedOutput: bigint): bigint {
  return (quotedOutput * (BPS - slippageBps)) / BPS;
}
```

Pool previews include the entry fee but use the last settled market state. Execution settles first, so funding, price PnL, collateral fees, reconciliation, or another transaction can change the result. For a settlement projection, use `NullV1Lens.previewMarket`; still enforce router minimums.

## Sepolia nUSDC example

This example deposits `1,000 MockUSDC` into the Receiver pool of an existing `nUSDC` market. It assumes configured `publicClient`, `walletClient`, and `account` objects.

```ts
import { parseAbi, parseUnits } from "viem";

const market = "0x..." as const; // discover from the canonical factory
const router = "0x78C1e4b5b8cbcec9aBDC2a6F353a2e91746B4e03" as const;
const nUsdc = "0x77508321f1EF8C707Cd5869557365468BCeD0613" as const;
const mockUsdc = "0x5A316865F2C9c261aD1B254C46788b6356d2F135" as const;

const marketAbi = parseAbi([
  "function collateral() view returns (address)",
  "function receiverPool() view returns (address)",
]);
const erc20Abi = parseAbi([
  "function balanceOf(address account) view returns (uint256)",
  "function approve(address spender, uint256 amount) returns (bool)",
]);
const vaultAbi = parseAbi([
  "function asset() view returns (address)",
  "function previewDeposit(uint256 assets) view returns (uint256 shares)",
]);
const poolAbi = parseAbi([
  "function previewDeposit(uint256 assets) view returns (uint256 shares)",
  "function deposit(uint256 assets, address receiver) returns (uint256 shares)",
]);
const routerAbi = parseAbi([
  "function depositMarket(address market, uint256 receiverAssets, uint256 payerAssets, uint256 minReceiverShares, uint256 minPayerShares, uint256 deadline, bytes[] updateData) returns (uint256 receiverShares, uint256 payerShares)",
]);

const [collateral, receiverPool, underlying] = await Promise.all([
  publicClient.readContract({
    address: market,
    abi: marketAbi,
    functionName: "collateral",
  }),
  publicClient.readContract({
    address: market,
    abi: marketAbi,
    functionName: "receiverPool",
  }),
  publicClient.readContract({
    address: nUsdc,
    abi: vaultAbi,
    functionName: "asset",
  }),
]);

if (collateral.toLowerCase() !== nUsdc.toLowerCase()) {
  throw new Error("This example requires nUSDC market collateral");
}
if (underlying.toLowerCase() !== mockUsdc.toLowerCase()) {
  throw new Error("This nUSDC deployment does not use MockUSDC");
}

const receiverAssets = parseUnits("1000", 6);
const payerAssets = 0n;
const quotedVaultShares = await publicClient.readContract({
  address: nUsdc,
  abi: vaultAbi,
  functionName: "previewDeposit",
  args: [receiverAssets],
});
const quotedPoolShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewDeposit",
  args: [quotedVaultShares],
});
const minReceiverShares = (quotedPoolShares * (10_000n - 50n)) / 10_000n;

const approvalHash = await walletClient.writeContract({
  account,
  address: mockUsdc,
  abi: erc20Abi,
  functionName: "approve",
  args: [router, receiverAssets],
});
await publicClient.waitForTransactionReceipt({ hash: approvalHash });

const updateData: readonly `0x${string}`[] = []; // only when the stored price is usable
await walletClient.writeContract({
  account,
  address: router,
  abi: routerAbi,
  functionName: "depositMarket",
  args: [
    market,
    receiverAssets,
    payerAssets,
    minReceiverShares,
    0n,
    BigInt(Math.floor(Date.now() / 1000) + 5 * 60),
    updateData,
  ],
});
```

Set a side's assets and minimum shares to `0n` to skip it. A zero minimum on an active side disables slippage protection.

## Deadline and update data

`deadline` is Unix time in seconds. The router reverts with `TransactionTooOld(deadline)` when `block.timestamp > deadline`.

Use nonempty `updateData` when the market requires a fresh push update. Fetch payloads from the oracle's data source:

- [Pyth update data](/contracts/oracles/pyth#update-data)
- [Chainlink update requirements](/contracts/oracles/chainlink#nonpayable-fee-zero-routing)

Pass `[]` only when the oracle's stored price is usable. For Pyth, the payable router pays the update fee from its pre-funded ETH balance. Do not attach ETH to `depositMarket`.

## Direct ERC-4626 deposit

Direct pool calls always use **market collateral units**. For an `nUSDC` market, wrap `MockUSDC` into `nUSDC` first, then approve the selected pool to spend `nUSDC`.

After the vault deposit confirms, use the actual `nUSDC` balance received as the pool's `assets` input. Do not reuse the original `MockUSDC` amount: vault underlying units and vault-share units can differ.

The direct call has no router deadline, output floor, oracle payload, or automatic vault wrap. Add those safeguards in your integration.
