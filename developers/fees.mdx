Null V1 charges three fee types. All values are basis points (1 bp = 0.01%). The protocol owner sets each fee; immutable onchain constants cap every fee at **500 bps (5%)**.

| Fee | Max | When | Accrues to |
| --- | --- | --- | --- |
| Entry | 500 bps | `deposit` / `mint` | `protocolFees` |
| Exit | 500 bps | `redeem` / `withdraw` | `protocolFees` |
| Collateral | 500 bps annualized | Each settlement, on pool balances over time | `protocolFees` |

Fees are swept only to the factory owner via `sweepFees()`.

## Entry fee

On `deposit`, the fee is included in assets paid (fee-on-total) and deducted before shares. On `mint`, the fee is added to the raw assets required (fee-on-raw).

**Example:** entry fee 50 bps, deposit 1,000 USDC → fee-on-total ≈ `ceil(1,000 × 50 / 10,050)` in raw units (~4.975 USDC at 6 decimals). ~995.025 USDC mints shares.

```ts
const entryFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "entryFee",
});
```

## Exit fee

On `redeem`, deducted from gross assets (fee-on-total). On `withdraw`, added to the raw pool debit needed to deliver net assets (fee-on-raw).

**Example:** exit fee 30 bps, gross 1,000 USDC → ~2.991 USDC fee; ~997.009 USDC to the user.

```ts
const exitFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "exitFee",
});
```

## Collateral fee

Annualized fee on Receiver and Payer balances during settlement — not a cut of measured yield. If collateral earns 5% externally and `collateralFee` is 100 bps, net collateral carry before funding is roughly 4%.

```text
pool fee = pool balance * collateralFee / 10,000 * elapsed / 365 days
```

Accrues into `protocolFees`, excluded from Receiver/Payer settlement until swept. See [Settlement](/developers/settlement).

```ts
const collateralFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "collateralFee",
});
```

## Read all fees

```ts
const [entryFee, exitFee, collateralFee] = await Promise.all([
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "entryFee" }),
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "exitFee" }),
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "collateralFee" }),
]);
```

## Previews already include fees

Do not apply a second manual deduction on top of `previewDeposit` / `previewRedeem`. They still use last settled state, and router ERC-4626 amounts are in vault underlying rather than collateral shares.

```ts
const sharesOut = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewDeposit",
  args: [assetsIn],
});

const assetsOut = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewRedeem",
  args: [sharesIn],
});
```

Use previews as fee-aware estimates, then add slippage. For ERC-4626 collateral, also apply vault wrap/unwrap before router minimums.
