Null V1 supports three fee types. All values are basis points (1 bp = 0.01%). Every market starts with all three values set to zero. The factory owner can set market-specific values with `setFees(entryFee, exitFee, collateralFee)`, subject to immutable **500 bps (5%)** caps.

| Fee | Max | When | Accrues to |
| --- | --- | --- | --- |
| Entry | 500 bps | `deposit` / `mint` | `protocolFees` |
| Exit | 500 bps | `redeem` / `withdraw` | `protocolFees` |
| Collateral | 500 bps annualized | Each settlement, on pool balances over time | `protocolFees` |

`setFees` settles using the old values before storing the new values. Read the market's current values instead of assuming a deployment default. Fees accrue to `protocolFees` and can be swept only to the factory owner via `sweepFees()`.

## Exact fee helpers

For raw integer asset amount `A`, fee basis points `b`, and `BPS = 10_000`, the contracts use:

```text
feeOnTotal(A, b) = ceil(A × b / (BPS + b))
feeOnRaw(A, b)   = ceil(A × b / BPS)
```

`feeOnTotal` extracts a fee from an amount that already includes the fee. `feeOnRaw` adds a fee on top of an amount before fees. Both round the fee up to the next raw collateral unit.

## Entry fee

On `deposit(A)`, the fee is included in the assets paid:

```text
entry fee        = feeOnTotal(A, entryFee)
assets for shares = A - entry fee
```

On `mint(shares)`, ERC-4626 conversion first calculates the raw assets `A` needed for those shares, then adds:

```text
entry fee  = feeOnRaw(A, entryFee)
assets paid = A + entry fee
```

```ts
const entryFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "entryFee",
});
```

## Exit fee

On `redeem(shares)`, ERC-4626 conversion first calculates gross assets `A`, then deducts:

```text
exit fee      = feeOnTotal(A, exitFee)
assets to user = A - exit fee
```

On `withdraw(A)`, `A` is the net amount requested by the user. The market debits the pool by:

```text
exit fee       = feeOnRaw(A, exitFee)
pool debit      = A + exit fee
assets to user  = A
```

```ts
const exitFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "exitFee",
});
```

## Collateral fee

The collateral fee is annualized on each prepared pool balance during settlement. It is not a cut of measured yield.

```text
pool fee = floor(floor(pool balance × collateralFee / 10,000) × elapsed / 365 days)
```

Each pool's fee is capped at that pool's balance. The fee accrues into `protocolFees` and is excluded from Receiver/Payer settlement until swept. If time has not advanced or `collateralFee` is zero, no collateral fee accrues. See [Settlement](/developers/settlement).

```ts
const collateralFeeBps = await publicClient.readContract({
  address: market,
  abi: marketAbi,
  functionName: "collateralFee",
});
```

## Read all fees

```ts
const [entryFee, exitFee, collateralFee] = await Promise.all([
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "entryFee" }),
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "exitFee" }),
  publicClient.readContract({ address: market, abi: marketAbi, functionName: "collateralFee" }),
]);
```

## Previews already include fees

Do not apply a second manual fee on top of any ERC-4626 preview. `previewDeposit`, `previewMint`, `previewWithdraw`, and `previewRedeem` already apply the corresponding formula.

Direct pool previews still use the last settled state, while execution settles first. For settlement-aware quotes, use `NullV1Lens.previewMarket` and apply the projected pool state to your integration. Router ERC-4626 amounts are in vault underlying rather than collateral shares.

```ts
const sharesOut = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewDeposit",
  args: [assetsIn],
});

const assetsOut = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewRedeem",
  args: [sharesIn],
});
```

Use previews as fee-aware estimates, then add slippage. For ERC-4626 collateral, also account for vault wrap or unwrap before setting router minimums.
