Redeeming burns Receiver or Payer pool shares and returns assets. Use `redeemMarket` for production UIs. It settles before conversion, enforces a deadline and minimum output, accepts oracle update data, and unwraps ERC-4626 collateral.

In the Null app, this action is called **Burn**. Contract integrations should use the ERC-4626 term `redeem`.

## Output units

Read `market.collateral()`, then probe the collateral token's `asset()` function:

| Market collateral                   | Router output and minimum units        |
| ----------------------------------- | -------------------------------------- |
| `asset()` reverts or is unavailable | Market collateral                      |
| `asset()` succeeds                  | Vault underlying returned by `asset()` |

The router uses the same detection rule. On Sepolia, redeeming a pool from an `nUSDC` market follows:

```text
Receiver or Payer pool shares → nUSDC vault shares → MockUSDC underlying
```

Use `nUSDC` and `MockUSDC` names only after verifying those addresses for the selected deployment.

## Quote the complete unit pipeline

For plain ERC-20 collateral:

```text
pool shares → pool.previewRedeem(shares) → collateral
```

For ERC-4626 collateral:

```text
pool shares
  → pool.previewRedeem(shares)
  → collateralVault.previewRedeem(vault shares)
  → underlying
```

Apply slippage once, to the final asset quote:

```ts
const BPS = 10_000n;
const slippageBps = 50n; // 0.50%

function applySlippageFloor(quotedOutput: bigint): bigint {
  return (quotedOutput * (BPS - slippageBps)) / BPS;
}
```

`pool.previewRedeem` includes the exit fee but reads the last settled state. `redeemMarket` settles before burning shares, so the result can change before execution. Use `NullV1Lens.previewMarket` for a settlement projection and keep the router minimum.

## Sepolia nUSDC example

This example redeems a caller's full Receiver balance from an existing `nUSDC` market. It assumes configured `publicClient`, `walletClient`, and `account` objects.

```ts
import { parseAbi } from "viem";

const market = "0x..." as const; // discover from the canonical factory
const router = "0x78C1e4b5b8cbcec9aBDC2a6F353a2e91746B4e03" as const;
const nUsdc = "0x77508321f1EF8C707Cd5869557365468BCeD0613" as const;
const mockUsdc = "0x5A316865F2C9c261aD1B254C46788b6356d2F135" as const;

const marketAbi = parseAbi([
  "function collateral() view returns (address)",
  "function receiverPool() view returns (address)",
]);
const poolAbi = parseAbi([
  "function balanceOf(address account) view returns (uint256)",
  "function approve(address spender, uint256 amount) returns (bool)",
  "function previewRedeem(uint256 shares) view returns (uint256 assets)",
  "function redeem(uint256 shares, address receiver, address owner) returns (uint256 assets)",
]);
const vaultAbi = parseAbi([
  "function asset() view returns (address)",
  "function previewRedeem(uint256 shares) view returns (uint256 assets)",
]);
const routerAbi = parseAbi([
  "function redeemMarket(address market, uint256 receiverShares, uint256 payerShares, uint256 minReceiverAssets, uint256 minPayerAssets, uint256 deadline, bytes[] updateData) returns (uint256 receiverAssets, uint256 payerAssets)",
]);

const [collateral, receiverPool, underlying] = await Promise.all([
  publicClient.readContract({
    address: market,
    abi: marketAbi,
    functionName: "collateral",
  }),
  publicClient.readContract({
    address: market,
    abi: marketAbi,
    functionName: "receiverPool",
  }),
  publicClient.readContract({
    address: nUsdc,
    abi: vaultAbi,
    functionName: "asset",
  }),
]);

if (collateral.toLowerCase() !== nUsdc.toLowerCase()) {
  throw new Error("This example requires nUSDC market collateral");
}
if (underlying.toLowerCase() !== mockUsdc.toLowerCase()) {
  throw new Error("This nUSDC deployment does not use MockUSDC");
}

const receiverShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "balanceOf",
  args: [account.address],
});

const quotedVaultShares = await publicClient.readContract({
  address: receiverPool,
  abi: poolAbi,
  functionName: "previewRedeem",
  args: [receiverShares],
});
const quotedUnderlying = await publicClient.readContract({
  address: nUsdc,
  abi: vaultAbi,
  functionName: "previewRedeem",
  args: [quotedVaultShares],
});
const minReceiverAssets = (quotedUnderlying * (10_000n - 50n)) / 10_000n;

const approvalHash = await walletClient.writeContract({
  account,
  address: receiverPool,
  abi: poolAbi,
  functionName: "approve",
  args: [router, receiverShares],
});
await publicClient.waitForTransactionReceipt({ hash: approvalHash });

const updateData: readonly `0x${string}`[] = []; // only when the stored price is usable
await walletClient.writeContract({
  account,
  address: router,
  abi: routerAbi,
  functionName: "redeemMarket",
  args: [
    market,
    receiverShares,
    0n,
    minReceiverAssets,
    0n,
    BigInt(Math.floor(Date.now() / 1000) + 5 * 60),
    updateData,
  ],
});
```

The approval is required even when the caller owns the shares. The router calls the pool as the spender and burns shares from `msg.sender`. Approve each active pool token separately.

Set a side's shares and minimum assets to `0n` to skip it. A zero minimum on an active side disables slippage protection.

## Deadline and update data

The deadline is Unix time in seconds. Expired calls revert with `TransactionTooOld(deadline)`.

Use nonempty `updateData` when the oracle requires a fresh push update:

- [Pyth update data](/contracts/oracles/pyth#update-data)
- [Chainlink update requirements](/contracts/oracles/chainlink#nonpayable-fee-zero-routing)

Pass `[]` only when the stored price is usable. Use `NullV1Router` for Chainlink and the pre-funded `NullV1PayableRouter` for Pyth. Do not attach ETH to `redeemMarket`.

## Direct ERC-4626 exit

Direct pool exits return **market collateral**. For an `nUSDC` market, they return `nUSDC`, not `MockUSDC`. Redeem the `nUSDC` separately if you need its underlying.

```ts
await walletClient.writeContract({
  account,
  address: receiverPool,
  abi: poolAbi,
  functionName: "redeem",
  args: [receiverShares, account.address, account.address],
});
```

If the transaction sender differs from the share owner, the owner must approve the sender. Direct calls have no router deadline, output floor, oracle payload, or automatic vault unwrap.
